CRM Capture

Send captured leads to your CRM.

Destination

Must be https. Saving asks Chrome for permission to reach this host — nothing is sent anywhere else.

For a bearer token, set the header to Authorization and the token to Bearer <your-token>. For an API key, use the header your CRM documents, e.g. X-API-Key.

Options

Sent with each lead so you can tell which machine it came from.

Off by default. Turn on to keep a local file as well — the only local fallback if the CRM is unreachable.
