CRM Capture

Send captured leads to a Google Sheet.

Google Sheet connection

Ends in /exec. Created when you deploy the script on your sheet — see setup below.

Must match SHARED_SECRET in the Apps Script. Without it, anyone holding the URL could write to your sheet.

Written to the sheet so you can tell which machine a lead came from.

Off by default. Turn on to keep a local file as well — a safety net if the sheet is unreachable.

Setup

  1. Open the Google Sheet. You need Edit access — view-only will not work.
  2. Extensions → Apps Script.
  3. Replace the contents of Code.gs with the script from apps-script/Code.gs, and set your own SHARED_SECRET.
  4. Deploy → New deployment → Web app. Execute as Me; Who has access Anyone.
  5. Copy the /exec URL into the field above, paste the same secret, then press Test connection.
